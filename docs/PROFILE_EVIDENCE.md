# Stage A field evidence and promotion
Each profile has data/sources/<id>.evidence.json with manufacturer URLs, field mappings, derivations/inferences and a needs-human review state. Null firmware properties and reviewer fields are unknowns, not sourced assertions. See proposed ADR014; human approval is required before accepting that clarification. Static generation uses explicit --allow-draft and labels its output. Default validation/API promotion rejects unreviewed records. Runtime additionally rejects missing firmware identity. No human sign-off is inferred from a JSON label.
